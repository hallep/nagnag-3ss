# NAGNAG 3 Splice Sites
Code developed and used for analyses presented in _The Role of NAGNAG 3' Splice Sites in the Flow of Genetic Information_

### Code

Scripts for data parsing and analysis are in `scripts`
To run all analyses, call `./run.sh`

Because HGMD data is not publically available, it is not provided here. Thus, for related analyses to run, you must copy provide it yourself. The program assumes that there is a folder named `HGMD_pro` in `src` containing the tab-delimited file `splice.txt`.
